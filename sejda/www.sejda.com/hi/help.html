Customizing Result File Names

Special keywords can be used as placeholders in the output file names, to be replaced with dynamic values during the execution.

A trivial example is prefixing each document with the page number, when splitting.

[CURRENTPAGE]

A reference to the current page number in the input document.

Example: [CURRENTPAGE###] will generate filesnames like 001.pdf, 002.pdf.
Example: [CURRENTPAGE##] generates 01.pdf, 02.pdf, etc.

[TIMESTAMP]

Ensures unique output filenames, being replaced with current date & time.

[FILENUMBER]

Ensures unique output filenames, replaced with a file number according to the output order.

Example: [FILENUMBER###] generates 001, 002
Example: [FILENUMBER13] starts with the counter at 13, generating 13, 14, etc.

[BASENAME]

Does not ensure unique output filenames, and it must be used together with other placeholders ensuring unique names. It is replaced with original name of the input document, without the extension.

Example: [CURRENTPAGE]_[BASENAME] would generate 1_input-file.pdf, 3_input-file.pdf, etc.

[BOOKMARK_NAME]

This pattern is replaced by current bookmark's name. Only applicable in the "Split by bookmarks" tool.

[BOOKMARK_NAME_STRICT]

Same behavior as [BOOKMARK_NAME] with the difference that non-alphanumberic characters are removed.

Example: [CURRENTPAGE]-[BOOKMARK_NAME] would generate 1-Introduction.pdf, 4-Chapter 1.pdf, etc.

[TEXT]

This pattern is applicable only in the "Split by text" tool. It is replaced with the text found in the page area selected.

Example: [CURRENTPAGE]-[TEXT] would generate 1-Invoice 3456789.pdf, 4-Invoice 234567.pdf, etc.

[TEXT1], [TEXT2], etc.

This pattern is applicable only in the "Rename" tool. It is replaced with the text found in the selected area.

Example: [TEXT2]-[TEXT1] would generate John Doe-Invoice 3456789.pdf, Jane Doe-Invoice 234567.pdf, etc.

Sejda Desktop can use your custom fonts when editing PDF documents.

1) Install the font on your system. See help for Windows or Mac.

2) Open Sejda Desktop, then open a PDF document with the Editor.

3) Type text on the page. From the context menu select "Fonts > More fonts".

5) Click on the newly added font to use it for your text.

Install Linux OCR engine

Sejda Desktop does not ship with an embedded OCR engine on Linux, it uses the one available on the system.

To install an OCR engine, please run the following command:

sudo apt-get install -y tesseract-ocr tesseract-ocr-all

Once the command completes, return to Sejda Desktop and run your OCR task again.

Install Linux OCR language data

The OCR engine is installed successfully, but it is missing language data.

To install language data, please run the following command:

sudo apt-get install -y tesseract-ocr-all

About 667M of data will be downloaded and installed.
Once the command completes, return to Sejda Desktop and run your OCR task again.

मुझे owner password डालने के लिए कहा जा रहा है

मुझसे password क्यों मांगा जा रहा है?

कुछ PDF documents सुरक्षा सेटिंग्स के साथ आते हैं जो कुछ कार्यों को प्रतिबंधित करते हैं, जैसे printing, text कॉपी करना, editing, या annotations जोड़ना. ये प्रतिबंध document बनाने वाले द्वारा लगाए जाते हैं ताकि यह नियंत्रित किया जा सके कि content का उपयोग और शेयर कैसे किया जाता है.

जब हमें पता चलता है कि किसी PDF में ये प्रतिबंध हैं, तो हम आपसे owner password मांगते हैं. यह password डालने से document अनलॉक हो जाता है और सभी फीचर्स और permissions का पूरा एक्सेस मिल जाता है. यह कदम यह सुनिश्चित करता है कि केवल अधिकृत व्यक्ति ही मूल लेखक द्वारा लगाए गए प्रतिबंधों को बदल या हटा सकें.

owner password क्या है?

owner password PDF बनाने वाले द्वारा सेट किया जाता है ताकि document में अनधिकृत बदलावों को रोका जा सके. यह user password से अलग है, जो document को खोलने से ही रोकता है. अगर आपके पास owner password है, तो इसका मतलब है कि आपके पास document की पूरी permission है.

अगर मेरे पास owner password नहीं है तो क्या होगा?

अगर आपके पास owner password नहीं है, तो PDF में सेट किए गए प्रतिबंधों के आधार पर आपके पास सीमित एक्सेस रहेगा.

पूरा एक्सेस पाने के लिए, document का अनलॉक किया हुआ version प्राप्त करें.

मैं हर बार owner password टाइप करने से कैसे बच सकता हूँ?

आप अपने document से permission प्रतिबंधों को हटाने के लिए PDF unlocker टूल का उपयोग कर सकते हैं. आपको यह केवल एक बार करना होगा. फिर आपसे document के लिए दोबारा owner password नहीं मांगा जाएगा.

PDF document को Google Chrome में खोलें, print करने के लिए Ctrl+P दबाएं, ऊपर दाईं ओर "Destination" में "Save as PDF" चुनें, फिर "Save" पर क्लिक करें.

क्या paid plan खरीदने से समस्या हल हो जाएगी?

नहीं, भले ही आपके पास हमारा paid plan हो, फिर भी आपसे owner password मांगा जाएगा.

क्या आप मुझे owner password बता सकते हैं?

नहीं, हमें आपके documents का owner password नहीं पता है. owner password उस व्यक्ति द्वारा चुना गया था जिसने आपका document बनाया था, और यह आपके login password से अलग है.

मैं scanned document को edit या convert नहीं कर पा रहा हूँ

scanned documents को edit या convert क्यों नहीं किया जा सकता?

जब आप PDF बनाने के लिए किसी भौतिक document को scan करते हैं, तो scanner प्रत्येक पेज की एक image कैप्चर करता है. यह प्रक्रिया text, graphics और layout को PDF के भीतर एक ही image फ़ाइल में बदल देती है. मानक PDF के विपरीत, जहाँ text को अलग-अलग अक्षरों और लाइनों के रूप में स्टोर किया जाता है जिन्हें चुना, कॉपी और edit किया जा सकता है, scanned PDF हर पेज को एक बड़ी तस्वीर की तरह मानते हैं.

चूँकि scanned PDF में text एक image का हिस्सा होता है, इसलिए PDF editors इसे सीधे पहचान या बदल नहीं सकते. सॉफ्टवेयर केवल pixels का एक संग्रह देखता है, अलग-अलग अक्षर या शब्द नहीं. यह text पैराग्राफ को edit करना या बदलाव करना असंभव बना देता है जैसा कि आप एक नियमित, text-आधारित PDF document में कर सकते हैं.

यह कैसे पता करें कि कोई document scan है?

यह पता लगाने का एक तरीका है कि क्या PDF एक scanned image है, इसे PDF viewer के साथ खोलें और अपने mouse से text चुनने की कोशिश करें. editable PDF में, आप text पर क्लिक करके और cursor खींचकर उसे highlight कर सकते हैं. यदि आप किसी text को चुनने में असमर्थ हैं और पूरा पेज एक सिंगल image की तरह व्यवहार करता है, तो संभावना है कि यह एक scanned document है.

नोट: कुछ scanned documents को "searchable" स्कैन बनाने के लिए Optical Character Recognition (OCR) के साथ प्रोसेस किया जाता है, जहाँ text को चुना और खोजा जा सकता है. हालाँकि, ये document अभी भी स्कैन ही हैं और इन्हें मानक PDF की तरह edit या convert नहीं किया जा सकता.

मुझे यकीन है कि मेरा document स्कैन नहीं है

कुछ document स्कैन की तरह लगते हैं क्योंकि उनका content हर पेज पर images के रूप में एम्बेडेड होता है. ऐसा स्क्रीनशॉट से बने documents के साथ या तब हो सकता है जब text को editable text के रूप में एम्बेड करने के बजाय आउटलाइन में बदल दिया गया हो.

हालाँकि ये तकनीकी रूप से स्कैन नहीं हैं, फिर भी ये उसी तरह काम करते हैं. दुर्भाग्य से, हम इस प्रकार के documents को edit या convert करने का समर्थन नहीं करते हैं.

क्या paid plan खरीदने से समस्या हल हो जाएगी?

नहीं, paid plan में अपग्रेड करने से आप scanned documents को edit या convert नहीं कर पाएंगे. स्कैन को edit या convert करना समर्थित नहीं है, चाहे आपका subscription लेवल कुछ भी हो.

मुझे यकीन है कि मैं पहले इस document को edit कर पा रहा था

हमने कभी भी scanned documents को edit या convert करने का समर्थन नहीं किया है. यदि आप पहले document को edit करने में सक्षम थे, तो संभावना है कि इसे वर्तमान document की तुलना में अलग तरह से PDF में एक्सपोर्ट किया गया था.

permissions के कारण Sejda Desktop विफल हो जाता है

इस एरर के 2 सामान्य कारण हैं: अपर्याप्त permissions या antivirus interference.

अपर्याप्त Permissions: आपको Sejda Desktop को Administrator privileges के साथ चलाने की आवश्यकता हो सकती है. ऐप पर Right-click करें, फिर "More" > "Run as administrator" चुनें.

Antivirus या Security software: यह देखने के लिए कि क्या इससे समस्या हल होती है, अपना antivirus कुछ समय के लिए disable करके देखें.

Chromebook पर Sejda Desktop Install करें

Sejda Desktop को Linux development environment (जिसे Crostini भी कहा जाता है) का इस्तेमाल करके Chromebook पर Install किया जा सकता है.

Requirements

आपके Chromebook पर Linux development environment enabled होना चाहिए. इसे enable करने के लिए, Settings → Advanced → Developers → Linux development environment पर जाएं और setup के स्टेप्स फॉलो करें.

सभी Chromebooks Linux सपोर्ट नहीं करते. पुराने या कम कीमत वाले मॉडल्स में शायद यह विकल्प न हो.

1. Linux (.deb) वर्शन Download करें

Download Sejda Desktop

2. इसे Terminal में Install करें

Linux Terminal ऐप खोलें और इसे चलाएं:

cd ~/Downloads
sudo dpkg -i sejda-desktop_*.deb
sudo apt -f install

3. इसे चलाएं

sejda-desktop

या फिर अपने ChromeOS लॉन्चर के Linux apps फोल्डर से इसे शुरू करें.

Troubleshooting: ऐप नहीं खुल रहा है

अगर Sejda Desktop दिखाई नहीं देता या विंडो नहीं खुलती, तो मिसिंग GUI libraries को install करें:

sudo apt install -y libgconf-2-4 libatk1.0-0 libatk-bridge2.0-0
