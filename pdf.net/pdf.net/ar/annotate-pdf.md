## FAQ

### Are my PDF files secure when using this tool?

Yes, your PDF files are secure when using this PDF annotator. Our servers are protected by the latest end-to-end encryption to keep your files and data private and protected.

### Can I undo or delete annotations after adding them?

Yes, you can undo or delete annotations after adding them as long as you have not downloaded the file yet. If you accidentally download a file with annotation mistakes, simply re-upload it to our online PDF editor to remove them.

### Can I annotate multiple PDFs at once?

No, you can’t annotate multiple PDFs at once in our online PDF editor. You need to upload each file separately to annotate it.

### Is there a limit to the number of pages I can annotate?

No, there’s no limit to the number of pages you can annotate. However, we have a 500 MB file size limit for the documents you can upload. As long as your file meets this limit, it doesn’t matter how many pages it contains.

### How do I edit or move an existing annotation?

To edit or move an existing annotation, you need a tool that can edit and write on PDFs, meaning a simple annotator won’t be enough. Fortunately, pdf.net has both a PDF editor and an annotation tool that you can use to update your file.

### Will my annotations be visible on all PDF readers?

No, your annotations might not be visible on all PDF readers because some applications don’t support the standard markups and highlights on PDF files.

### How do I remove annotations from a PDF?

To remove annotations from a PDF, use pdf.net’s online tool for annotating documents and editing PDF files. After uploading your file, simply select and delete the annotation you want to remove and then download the updated document.

### Is it possible to annotate scanned PDF documents?

Yes, it’s possible to annotate scanned PDF documents with pdf.net. All you need to do is follow the same steps for annotating regular PDF files.

### Can I annotate encrypted or password-protected PDFs?

No, you can’t annotate encrypted or password-protected PDFs. To do so, you would need to save its contents in a separate file and add your annotations there.

### Can I use pdf.net on a Mac, Linux, or smartphone?

Yes, you can use pdf.net on a Mac, Linux, or smartphone to write on a PDF online. As a cloud-based platform, our editor can be accessed on virtually any device or browser with an internet connection.

### What file formats can I annotate?

Mark up PDF files online with highlights, drawings, and comments. You can also upload Word documents (DOC, DOCX) and JPG and PNG images, and your file opens in the editor.
