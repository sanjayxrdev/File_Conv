Soalan lazim

Apakah itu fail .md?
Fail .md ialah fail teks biasa yang ditulis dalam Markdown, iaitu sintaks pemformatan ringan yang menggunakan simbol ringkas seperti (#) untuk tajuk, (-) untuk senarai, dan (**) untuk teks tebal. Ia digunakan secara meluas untuk dokumentasi, fail README dan nota kerana ia mudah dibaca seadanya dan mudah ditukar kepada format lain.
Bolehkah saya menukar Markdown kepada PDF?
Ya, anda boleh menukar Markdown kepada PDF dengan pdf.net. Penukar dalam talian kami mengambil Markdown teks biasa anda, seperti tajuk, senarai, jadual, blok kod dan pautan, lalu memaparkannya sebagai PDF yang diformat secara profesional dan boleh dikongsi. Tiada CLI, templat atau saluran penerbitan diperlukan.
Bagaimana untuk menukar fail Markdown kepada PDF?
Buka penukar Markdown kepada PDF kami dalam talian dan seret fail .md anda ke kawasan muat naik, atau klik untuk memilihnya. Jika anda lebih suka melangkau muat naik fail, anda boleh menampal Markdown anda terus dan menukarnya kepada PDF.
Format fail Markdown yang manakah disokong?
Penukar Markdown kepada PDF kami menerima fail .md dan .markdown, serta apa-apa teks Markdown yang ditampal. Selain itu, penukar ini menyokong sepenuhnya Standard Markdown, contohnya CommonMark dengan sambungan GitHub Flavored (GFM) seperti jadual, blok kod berpagar, senarai tugasan dan coretan.
Adakah penukar MD kepada PDF ini mengekalkan pemformatan untuk blok kod dan jadual?
Ya, alat MD kepada PDF kami mengekalkan blok kod berpagar dengan tipografi monospace, jadual dengan penjajaran lajur yang betul, senarai bersarang dan bernombor, petikan blok, pautan dan penegasan sebaris. Kod sebaris dan sampel kod berbilang baris kedua-duanya dipaparkan dengan kemas dalam PDF akhir.
Bolehkah saya menukar Markdown yang dijana oleh ChatGPT, Claude atau ejen AI lain?
Ya, anda boleh menukar Markdown yang dijana oleh ChatGPT, Claude atau ejen lain kepada PDF. Ini ialah salah satu cara yang paling biasa individu gunakan penukar Markdown kepada PDF dalam talian kami. Tajuk, senarai bertitik, senarai bernombor, jadual, blok kod berpagar, kod sebaris, petikan blok dan pautan semuanya dipaparkan dengan betul. Selepas itu, anda boleh menggunakan editor PDF kami untuk menambah gambar, menandatangan, membuat anotasi dan banyak lagi sebelum memuat turun atau berkongsi.
Bolehkah saya menukar Markdown daripada GitHub, Obsidian atau Notion?
Ya, anda boleh menukar Markdown daripada GitHub, Obsidian atau Notion dengan penukar MD kepada PDF kami. Hanya salin Markdown daripada sumber anda dan tampalkannya ke dalam alat kami. Sambungan GitHub Flavored Markdown seperti jadual, senarai tugasan dan blok kod berpagar semuanya disokong secara terus.
Bolehkah saya mengedit PDF selepas menukar daripada Markdown?
Ya, anda boleh mengedit PDF selepas menukar daripada Markdown. Editor PDF dalam talian kami membolehkan anda membuat anotasi, menambah teks atau imej, menyusun semula atau memadam halaman, menandatanganinya dan mengeksport fail akhir apabila anda sudah bersedia. Apa-apa perubahan yang anda buat dalam editor tidak menjejaskan Markdown asal anda.
Bolehkah saya menukar Markdown kepada PDF tanpa memasang apa-apa?
Ya, anda boleh kerana penukar Markdown kepada PDF kami berjalan sepenuhnya dalam pelayar anda. Tiada CLI untuk disediakan, tiada pemasangan pandoc, tiada rantaian alat LaTeX dan tiada langkah binaan. Tampal atau lepaskan Markdown anda, dan dapatkan PDF dalam masa beberapa saat pada mana-mana peranti, di mana-mana sahaja.
Adakah penukar Markdown kepada PDF ini percuma?
Ya, penukar Markdown kepada PDF kami adalah percuma untuk digunakan. Walau bagaimanapun, memuat turun hasil atau menggunakan editor PDF penuh untuk memperhalusi output memerlukan langganan.
Adakah fail Markdown saya peribadi?
Ya, fail Markdown anda kekal peribadi. pdf.net menyulitkan fail semasa penghantaran dan semasa disimpan, dan tidak menyimpannya untuk jangka panjang. Kandungan Markdown anda dan PDF yang dijana kekal milik anda kerana kami tidak pernah menggunakan dokumen yang dimuat naik untuk melatih model atau berkongsinya dengan pihak ketiga.
