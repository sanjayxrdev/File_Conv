## FAQ

### What is an .md file?

An .md file is a plain-text file written in Markdown, which is a lightweight formatting syntax that uses simple symbols like (#) for headings, (-) for lists, and (**) for bold. It's widely used for documentation, README files, and notes because it's readable as-is and easy to convert to other formats.
