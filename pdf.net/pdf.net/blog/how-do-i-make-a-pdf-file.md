> The answer to the question, “How do I make a PDF file?” is multifaceted, as there are several formats and tools you can use to create one.

You can make a PDF file using one of the **pre-installed programs** on your computer, like Microsoft Office, or using cloud-based tools like Google Docs or a dedicated **PDF maker tool**.

Once you learn how to make a PDF file, your documents will be more **readable**, **professional-looking**, and **easier to share**. Unlike some other file formats, PDF is platform-independent, and its relatively compact size makes PDF files easier to store, download, and transfer.

In this PDF creation guide, we’ll answer the “How do I create a PDF file?” question by explaining seven different methods of doing so. Let’s begin!

## Key Takeaways

- You can easily create PDFs from **Microsoft Office** programs like Word, Access, Publisher, Excel, and PowerPoint using the built-in **Export** or **Save as PDF/XPS** options—no additional software needed.
- Google Workspace apps such as **Docs, Sheets, and Slides** allow you to download documents as PDFs directly.
- **Apple tools** (Keynote, Numbers) and browsers like **Chrome, Safari, Edge, and Firefox** also let you export or print to PDF for quick conversions.
- You can create PDFs from **scanned documents** or **images** by using the “Microsoft Print to PDF” or “Export as PDF” feature on Windows and Mac.
- With **pdf.net**, you can convert, edit, split, merge, or annotate PDFs online, with no installation required.

## How to Create a PDF File from Microsoft Office Products

You can create a PDF file using Microsoft Office programs with no other software or add-in.

Here’s how you can create a PDF from text, data, and designs with Microsoft Word, Access, and Publisher:

**Microsoft Word**:

1. Open the document you want to convert from [Word to PDF](https://pdf.net/word-to-pdf).
2. Select the _File _tab from the [Ribbon](https://itstraining.wichita.edu/microsoft-office-customizing-the-ribbon/).  
![Select the File tab from the Ribbon](https://cdn.sanity.io/images/i16te7yp/production/6ce7515e15d0417c0ec25a7d3b3d8b57e1b2a3a0-1920x224.png?fit=max&auto=format)
3. Click the _Export _button in the drop-down menu on the left.  
![Click the Export button in the drop-down menu on the left](https://cdn.sanity.io/images/i16te7yp/production/377a8765d2411a0444bc961d093b68c327e6805c-1920x1030.png?fit=max&auto=format)
4. From there, select the _Create PDF/XPS Document_ option and confirm it by clicking the _Create PDF/XPS_ button in the right pane.
5. Enter the name of the document and save it.

**Microsoft Access**:

1. Choose the report or table you want to convert to PDF.
2. Select the _External Data _tab and choose the _PDF or XPS_ option.  
![Select the External Data tab and choose the PDF or XPS option](https://cdn.sanity.io/images/i16te7yp/production/7b081747f6796db5c0660d0b3c64db3d3253e6b2-1919x174.png?fit=max&auto=format)
3. Type in the name and save the document.

**Microsoft Publisher**:

1. Select the document you want to convert from Publisher to PDF.
2. Open the _File _menu.
3. Select the _Save As_ option from the drop-down menu on the left and choose a location for the file you’re creating.
4. Choose the folder from the right pane.  
![Choose the folder from the right pane](https://cdn.sanity.io/images/i16te7yp/production/a1784f2f539b61b80272c0192725f45b6010d843-1342x246.png?fit=max&auto=format)
5. Enter the document’s name, choose the PDF format from the _Save as type_ list, and then tap on _Save_.

## How to Make a PDF Document from Spreadsheets and Presentations

## How to Create a PDF File from Scanned Documents

Creating a PDF file from a scanned document allows you to keep its original layout and content while making it easier to [share online](https://pdf.net/blog/how-to-share-pdfs).

Here’s how to make a PDF file from a scanned document:

1. Open the document you want to convert to PDF.
2. Tap on the printer icon in the top bar.  
![Create a DF file from a scanned document](https://cdn.sanity.io/images/i16te7yp/production/ee8352afcb5bbc776a28b381d1084cbbd292c2fe-1914x60.png?fit=max&auto=format)
3. Choose the_ Microsoft Print to PDF _option from the drop-down menu.
4. Tap on _Print_, choose the location for the file, enter a name for it, and click _Save_.

## How to Save Webpages as PDFs on Desktop and Mobile

Saving webpages as PDFs lets you preserve the entire page, including formatting, links, and images for offline viewing and sharing.

Let’s see how you can do that from a computer and a mobile device.

### #1. Using a Browser (Chrome, Safari, Edge, Firefox)

Let’s see how you can convert a [webpage to PDF](https://pdf.net/blog/download-webpage-as-pdf) using a browser, whether you’re a Windows or Mac user.

**Windows**:

1. Open the webpage and press Ctrl+P to open the print menu.  
![Open the webpage and press Ctrl+P to open the print menu.](https://cdn.sanity.io/images/i16te7yp/production/c1df82f55e498cacef8b4d184024ceb597beb248-1896x855.png?fit=max&auto=format)
2. From the _Destination _drop-down menu, choose the _Save as PDF_ option.
3. Select _Save _and choose the name and location for your file.

**Mac**:

1. Press Command+P to open the print menu.
2. Select the _Save as PDF_ option from the drop-down menu in the upper right corner and click _Save_.  
![Select the Save as PDF option from the drop-down menu](https://cdn.sanity.io/images/i16te7yp/production/db2b34ee54b8e388908685dc9103409a1e14674d-1300x855.png?fit=max&auto=format)
3. Choose the location and name for the file and save it.

### #2. From Mobile

Here’s how you can save a webpage as a PDF file from a mobile device:

1. Select a mobile browser and load the webpage you want to save.
2. Tap on the three dots in the upper right corner and choose the _Share _option from the drop-down menu.  
![Save a webpage as a PDF file from a mobile device](https://cdn.sanity.io/images/i16te7yp/production/0a13dff803a83d71c78ccb79b6856702152a2af7-1080x151.jpg?fit=max&auto=format)

![Select the printer icon](https://cdn.sanity.io/images/i16te7yp/production/0d35b0b51c750b967468ade0b56f7ad0521fad64-1080x289.jpg?fit=max&auto=format)
4. Click _Save as PDF_.
