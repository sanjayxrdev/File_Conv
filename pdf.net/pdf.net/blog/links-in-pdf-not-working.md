Links in a PDF are usually not working because the link was not added correctly, the file was converted from another format, the PDF is corrupted, your viewer does not support links, or your security settings are blocking them.

This is a common problem because **a PDF is a static file, and any hyperlink inside one depends entirely on how it was created, saved, and opened**. A link that works perfectly in the original document can easily stop working the moment the file is converted, resaved, or opened in a different program.

In this guide, we will cover the most common reasons behind broken PDF links and walk you through how to fix each one, including issues specific to Chrome.

## Key Takeaways

- Broken links in a PDF are usually caused by incorrect link creation, format conversion, file corruption, unsupported viewers, or restrictive security settings.
- Each cause has a specific fix, from re-adding the hyperlink to adjusting your PDF reader's settings.
- You can make links clickable in a PDF using a few simple editing steps.
- Chrome's built-in PDF viewer is a frequent source of link problems and usually needs a separate fix.
- Keeping your PDF viewer and browser updated prevents most future link issues.

## Why Are Links in a PDF Not Working?

Links in a [PDF file](https://pdf.net/blog/what-does-pdf-format-mean) may not be working for a handful of predictable reasons, ranging from how they were created to how the file is opened. Here are the five most common ones and what to do about each one.

### #1. The PDF Links Were Not Added Correctly

Many broken links **start at the source**. For instance, if a link was pasted as plain text instead of a real hyperlink, or if it was added incorrectly during editing, it can look clickable without actually working. This is one of the most common reasons behind PDF links not working, especially in documents built from templates or copied from another file.

**Fix: **Open the PDF in an editor that supports hyperlink editing and check whether the text is a live hyperlink or just formatted to look like one. If it is plain text, recreate the hyperlink and test it before sharing the file again.

### #2. The PDF Was Converted From Another Format

Converting a document to PDF can** strip out hyperlinks if the original formatting was not preserved**. This happens most often when [converting a Word document to PDF](https://pdf.net/word-to-pdf) with an outdated tool, or when a presentation or spreadsheet is exported without its embedded links intact.

**Fix: **Re-export the original file using a converter that preserves hyperlinks, then open the new PDF and click each link to confirm it still works. If links are still missing, add them back manually in your PDF editor.

### #3. The PDF File Is Corrupted

![links in pdf not working](https://cdn.sanity.io/images/i16te7yp/production/4ecce0561d350da1484cad9b03a6d962dff49cef-1200x896.jpg?fit=max&auto=format)

A corrupted PDF can lose more than just its links. Corruption usually happens **during an interrupted upload, a failed download, or an error while saving the file**, and it can affect text, images, and clickable elements at the same time.

**Fix: **Check whether other parts of the document look correct and whether there’s any [missing text](https://pdf.net/blog/pdf-missing-text) or garbled content. Otherwise, ask the sender for a fresh copy or re-download the original file.

### #4. Your PDF Viewer Does Not Support Links

Not every PDF viewer handles interactive elements the same way. Some lightweight or outdated readers only display the page content and ignore embedded hyperlinks, based on how each application implements the [PDF specification](https://pdfa.org/resource/iso-32000-2/), which means a perfectly working link can appear broken simply because of the software you are using.

**Fix: **Open the file in a different, up-to-date [PDF reader](https://pdf.net/blog/best-pdf-readers) to see whether the links work there. If they do, the issue is your original viewer, not the PDF itself.

### #5. Security Settings Are Blocking Links

Many PDF readers **restrict what a document can do by default**, including opening external links, as a way to prevent phishing and malware. [Government guidance on PDF reader security](https://media.defense.gov/2022/Jan/20/2002924940/-1/-1/0/CTR_CONFIGURING_ADOBE_ACROBAT_READER_20220120.PDF) recommends these restrictions specifically because malicious PDFs have used hyperlinks to redirect users to harmful sites.

**Fix: **Check your PDF reader's trust or security settings and enable hyperlinks in PDFs from known senders. You can also try [adjusting your PDF's permissions](https://pdf.net/blog/how-to-change-pdf-permissions) if the file itself is restricting certain actions.

Let’s reiterate all the issues along with their fixes:

| **Cause** | **Likely Symptom** | **Quick Fix** |
| --- | --- | --- |
| Link not added correctly | Text looks clickable, but does nothing | Re-add the hyperlink manually |
| Format conversion | Links vanish after exporting to PDF | Re-export or add links back in |
| Corrupted file | Links, text, or images look broken | Get a fresh copy of the file |
| Unsupported viewer | Links work in one app but not another | Switch to an updated PDF reader |
| Security settings | Link click produces a warning or does nothing | Adjust trust or permission settings |

## How to Make Links Clickable in a PDF

To make a link clickable in a PDF, you should:

1. Open your PDF in [our PDF editor](https://pdf.net/change-text-in-pdf). Upload the file directly from your device or cloud storage.

2. Select the text or image you want to turn into a link.

3. Choose the link type: a web address, an email address, or a jump to another page in the same document.

4. Paste in the destination URL or address and confirm the link.

5. Save the file, then click the new link to confirm it opens correctly before sharing it.

This process works the same way whether you are linking to a website, a file, or a specific section of a long document. If you are updating several links at once, it is worth testing each one individually, since a single broken URL is often the reason a document is flagged for embedded links in PDF not working.

## PDF Links Not Working in Chrome: How to Fix It?

![links in pdf not working](https://cdn.sanity.io/images/i16te7yp/production/1071b3c93cfe80e88a561342ab6cab80668ed377-1200x896.jpg?fit=max&auto=format)

PDF hyperlinks not working in Chrome are usually **caused by the browser's built-in viewer**, which does not always handle [interactive elements](https://pdf.net/blog/how-to-make-pdfs-interactive) the same way a dedicated PDF reader does. Switching how you open the file typically resolves the issue.

You should try these ways to fix links in a PDF in order:

1. [Download the PDF](https://pdf.net/blog/how-to-download-pdf-from-a-link) instead of viewing it in the browser, then open it with a dedicated reader.
2. Open the file with another PDF reader installed on your device.
3. Disable browser extensions that may be interfering with PDF rendering, then reload the page.
4. Clear your browser cache, since outdated cached data can prevent links and other elements from loading correctly.

If none of these steps fix the issue, [Chrome's PDF viewer troubleshooting steps](https://www.uhd.edu/computing/training-lms/troubleshooting-chrome-pdf-viewer.aspx) cover a few additional settings worth checking, including your default viewer configuration. Testing the same file on another device can also help you confirm whether the problem is specific to your browser and why hyperlinks in the PDF are not working.

## Links in PDF Not Working FAQ

### #1. Can I fix broken links in a PDF online?

Yes, **you can fix broken links in a PDF online** using a browser-based PDF editor, such as pdf.net. All you should do is upload the file, select the broken link or the text around it, and add or correct the destination URL before saving and re-sharing the document.

### #2. Why do PDF links stop working after saving?

PDF links often stop working after saving **because the file was flattened, re-exported, or saved in a way that strips interactive elements**. Re-adding the hyperlinks after saving, or using a converter that preserves them, usually solves the problem.

### #3. Why don't links work in a password-protected PDF?

Links may not work in a [password-protected PDF](https://pdf.net/blog/how-to-password-protect-a-pdf) **because the security settings restrict certain actions until the document is unlocked**. If you [forgot your PDF password](https://pdf.net/blog/forgot-pdf-password) or need to remove restrictions, unlocking the file first will usually restore normal link behavior.

### #4. Do PDF hyperlinks work on mobile devices?

PDF hyperlinks **generally work on mobile devices**, but the experience depends on the app used to open the file. If a link does not respond on your phone or tablet, try opening the PDF in a dedicated reader app instead of a browser preview.
