Alternative Methods for Creating Fillable PDFs

Besides using pdf.net, there are alternative ways to create fillable PDFs, including Google Docs, MS Word, and Preview.

Let’s examine these methods in detail:

Create a Fillable PDF with Google Docs

You can use Google Docs to create a fillable PDF from scratch or add fillable fields to an existing document. Although not the easiest, this method is also not the most complicated.

Here are the steps to make a fillable PDF in Google Docs:

1. Sign in to your Google account and find your drive.

2. Click the New button and choose the file from your storage to upload it (a blank or existing document).

3. Locate the file on the drive, right-click it, choose Open with, and select Google Docs.

4. Click the Insert button at the top left, place the cursor on Table, and choose the dimensions; for open-ended text boxes, add a single-cell table.

5. In the table, add placeholder text to check how it fits.

6. Set the border width to ‘zero’ to erase the table borders by clicking the Border Width icon in the upper-right corner.

7. For a drop-down fillable form, click the Insert button and select Dropdown.

8. Choose the type of drop-down and place it in the table.

9. To create multiple-choice forms, add a list, select it, click the Bulleted list menu, hover over the Checklist menu, and select the preferred option.

10. Click File, Download, and choose PDF document (.pdf) to finalize this process.

Create a Fillable PDF with MS Word

The steps to make a fillable PDF in Word are similar to the ones in Google Docs. Word also lets you create PDFs from scratch or add fillable forms to existing files.

Let’s take a closer look at the steps:

1. Open MS Word and click Blank document, or right-click your existing file, select Open with, and choose Word.

2. Enable the Developer ribbon by choosing File>Options>Customize Ribbon, where you should tick the Developer feature and click OK.

3. Click the Developer ribbon, and choose the form you want to add (text, combo box, check box, etc.).

4. Modify your fields by selecting them and clicking on the Properties option within the ribbon.

5. Click File, choose Save As, decide the name and the saving location for your file, select PDF, and click Save to complete the process.

Create a Fillable PDF with Mac Preview

Preview on Mac is another way to make PDFs with fillable forms or add such forms to existing documents.

Let’s learn more about this method:

1. Open Preview, select File>New>Blank Document or right click the file you want to edit, hover over the Open With menu, and choose Preview.

2. Click the Markup tool in the top-right corner.

3. Use the Textbox tool to add fillable text forms, which you can later resize, edit, and adjust based on your needs.

4. Click File and select Save for existing PDF or choose Export as PDF for new documents.

5. Choose the name and destination folder, and click Save.

Although this alternative method allows you to create fillable PDFs for free, it does not offer adding advanced fillable forms such as checklists and drop-downs.
