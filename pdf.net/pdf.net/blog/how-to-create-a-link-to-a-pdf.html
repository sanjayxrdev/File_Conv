How to Create a Link to a PDF: A Step-by-Step Guide

You can create a link to a PDF by uploading it to Google Drive, Dropbox, or OneDrive and updating its permissions to ‘Anyone with the link’.

You can create a link to a PDF by uploading it to Google Drive, Dropbox, or OneDrive, then setting the sharing permissions to “Anyone with the link can view”. Such links are great for sharing various types of documents, from short ones like invoices to longer ones like guides and reports.

Forming a link that redirects to a PDF is convenient because you are likely already using cloud platforms in your workflow. Before uploading, though, you would want to ensure your PDF is polished; for this, you can easily use online editors, like pdf.net.

In this guide, we will show you how to create a link to a PDF and share it via a hyperlink or HTML code. We will also provide tips on how to ensure your PDF is organized and optimized for sharing, so read on!.

What Does It Mean to Create a Link to a PDF?

Creating a link to a PDF means providing a clickable URL within an element such as a button, image, or text that opens or downloads the file when you click it. It is different from embedding a PDF, which displays the content of your document directly so others can view it without being redirected elsewhere.

You can link to a PDF in an email, in another document, on a website, or on social media. This keeps your page loading fast and easy to share with others. For example, instead of loading a 20-page report on your webpage, which can cause lagging, crashing, or missing text, it is better to link to it.

In addition, it is easier to update in the future, as you can replace the hosted PDF instead of re-embedding your content entirely. Linking to a PDF is particularly useful for PDF brochures, forms, whitepapers, guides, or any file others might want to look through at their own pace or download a copy to keep and refer back to.

How to Create a Link to a PDF Using Cloud Storage

To create a link to a PDF using cloud storage, you can upload your file to Google Drive, Dropbox, or OneDrive. Alternatively, you can use pdf.net to create a shareable link in seconds. That said, let’s take a closer look at each option:

#1. Google Drive

Follow these simple steps to upload your PDF and get the link to it:

  1. Open Google Drive.
  2. Click New > File upload and select your PDF to upload it.
  3. Right-click on your uploaded PDF and select Share.
  4. Click the drop-down arrow next to Restricted under General access.
  5. Select Anyone with the link and click Done.
  6. Select Copy link.
  7. Paste the link wherever you need as a hyperlink to your PDF.

#2. Dropbox

Here is how to make a link to a PDF on Dropbox:

  1. Open Dropbox.
  2. Upload your PDF file by clicking Upload or drag and drop it into Dropbox.
  3. Hover over the PDF file you have just uploaded and click the three dots (More).
  4. Select Manage permissions.
  5. Click the Settings icon next to Link for viewing.
  6. Click the drop-down menu next to Who has access and choose Anyone with link.
  7. Click Copy link next to People with this link can view.
  8. You can share the PDF via this link anywhere now.

#3. OneDrive

Create your PDF link via OneDrive by following these steps:

  1. Open OneDrive.
  2. Click Create or upload > Files upload to add your PDF document to OneDrive.
  3. Click the three dots next to your PDF document and select Manage access.
  4. Click the Links tab > Create and share a new link.
  5. Add the email addresses you want to share the PDF with and choose Can edit or Can view by clicking the drop-down menu.
  6. Alternatively, click the lock icon under Anyone with the link can edit to share.
  7. Click Copy link.
  8. Paste the link to your PDF where needed.

How to Add a Link to a PDF in a Document or Website

To add a link to a PDF in a document or on a website, you can either hyperlink it or use HTML code.

#1. Word, PowerPoint, or Email

In Word or PowerPoint, or email, you can highlight the text you want to turn into a link, right-click it, press Cmd+K (Mac) or Ctrl+K (Windows), paste the link in the input field, and press Enter.

Test that the link works by clicking on the text; it should open the PDF in a new browser tab. Hyperlinking will also work for images and other elements, such as buttons, in Word and PowerPoint.

#2. HTML Code

If you are adding the PDF link on a website, you can use an HTML code like <a href="https://yourwebsite.com/filename.pdf" target="_blank">Download our brochure (PDF)</a>

This will create clickable text that opens your PDF in a new browser tab, similar to the hyperlinking method above. You can also insert this HTML code to wrap around an image or a button.

How to Create a Link to a Specific Page in a PDF

To create a link to a specific page in a PDF, you need to add a page reference to the URL. If your PDF is hosted online, add #page=[number] at the end of the file link. For example, https://yourwebsite.com/guide.pdf#page=5.

This is useful when you want to make it easy for your viewers to see a certain section of your document without having to scroll or search the PDF. Some common cases might be referencing information in user guides, manuals, proposals, training materials, policies, and website resources.

How to Create a Link to a PDF FAQs

#1. Can I create a PDF link without using Google Drive?

Yes, you can create a PDF link without using Google Drive by using Dropbox or OneDrive instead. This is especially handy if you already work within Microsoft's software ecosystem.

#2. How do I make a PDF open directly in the browser?

To make a PDF open directly in the browser, use a direct link that ends in .pdf; for example, https://yourwebsite.com/file.pdf. Most modern browsers will automatically preview it, but if not, ensure server settings or headers are configured to display rather than force download.

#4. Where do I find the URL for a PDF?

You can find the URL for a PDF if it’s hosted online by opening the file in your browser and copying the address bar link. If it’s stored in Google Drive, Dropbox, or similar, you should use that service’s Share / Copy link option. Meanwhile, local files on your computer don’t have URLs until you upload them.
