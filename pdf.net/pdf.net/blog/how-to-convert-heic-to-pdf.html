What Is HEIC & Why Doesn’t It Convert Smoothly?

HEIC is Apple's preferred photo format, built on the HEIF (High Efficiency Image File Format) container standard. This format was designed to store images at roughly half the file size of JPEG while maintaining comparable or better visual quality. Apple adopted HEIC as the default camera format beginning with iOS 11.

The problem is that HEIC is not universally supported. Windows without the correct codec cannot open HEIC files at all. Many web platforms, email clients, and print services only accept JPEG, PNG, or PDF, and even some older Mac apps struggle with it.

There is one other thing worth knowing before you convert: if your iPhone captured a Live Photo or a photo burst as HEIC, those motion and sequence elements do not survive the conversion; the resulting PDF contains a static image only. For most document and sharing workflows, that is exactly what you want; just do not expect an animated or interactive file on the other side.

How to Convert HEIC to PDF on iPhone

To convert HEIC to PDF on iPhone, you should use the Print panel, which provides a reliable workaround and works on modern versions of iOS, as the iPhone has no dedicated "Export as PDF" button for photos.

How to Convert a Single HEIC File

Converting a single HEIC file on iPhone goes like this:

  1. Open the Photos app and tap the image you want to convert.
  2. Tap the Share icon (the box with an upward arrow).
  3. Scroll down the share sheet and tap Print.
  4. On the print preview screen, place two fingers on the preview thumbnail and pinch outward (the same gesture you use to zoom in). This opens the image as a full PDF preview.
  5. Tap the Share icon again from within this PDF preview.
  6. Tap Save to Files and choose a destination folder.

The file saves as a PDF. No third-party app required.

How to Convert Multiple HEIC Images Into One PDF

For converting several HEIC images into one PDF document on iPhone, the workflow is slightly different:

  1. Open the Files app.
  2. Tap the three-dot menu (ellipsis) in the upper right toolbar and click Select.
  3. Select all the images you want to include.
  4. Tap the three-dot menu (ellipsis) in the lower toolbar.
  5. Choose Quick Actions > Create PDF. Files combines all selected images into a single multipage PDF in the same folder.

This "Create PDF" option is available in Files on iOS 15 and later. If you need precise control over page order, arrange the files in your preferred sequence before selecting them, since the app follows the selection order.

How to Convert HEIC to PDF on Mac (Single File)

Preview is the fastest route to convert HEIC to PDF on macOS, and it handles HEIC natively without any additional software.

  1. Locate the HEIC file in Finder.
  2. Double-click to open it in Preview (or right-click > Open With > Preview if another app intercepts the file).
  3. Click File in the menu bar, then select Export as PDF…
  4. Choose a filename and save location in the dialog box, then click Save.

Preview does not give you explicit quality controls during PDF export, but it embeds the image at its native resolution by default. The output quality is generally very good as long as the original HEIC was shot at full resolution.

Tip: if you see Export... rather than Export as PDF..., click it and then select PDF from the Format dropdown. Both paths lead to the same result.

How to Convert HEIC to PDF on Mac in Batch

For contracts, property inspection reports, or any situation where several photos need to become a single document, Preview can batch-convert a folder of HEIC files into one multipage PDF.

  1. Select all the HEIC files in Finder (click the first, then Shift-click the last, or Command-A to select all).
  2. Right-click the selection and choose Open With > Preview. All images open as a sidebar filmstrip in a single Preview window.
  3. Make sure all thumbnails are selected in the sidebar (Command-A).
  4. Go to File and select Export as PDF.
  5. Name the file and choose a save location, then click Save.

The result is a single PDF with one image per page, in the same order as the sidebar.

When to Combine vs. When to Keep Your Files Separate

If you are preparing a set of site photos for a construction report or combining scanned receipts for an expense claim, a single merged PDF is easier to share and sign. If each image represents an independent document (for example, separate ID cards for different individuals), keep them as separate PDFs and merge PDF files only when needed.

How to Convert HEIC to PDF on Windows

Windows gives you two practical paths for converting HEIC to PDF, depending on whether you can install additional software on the machine. The recommended route uses Microsoft's free HEIF extension, while the second works even on locked-down or managed devices where installing extensions isn't an option.

Option A: Install the HEIF Image Extension (Recommended)

Windows does not support HEIC out of the box. As documented by Microsoft (updated June 19, 2026), the HEIF Image Extension must be installed from the Microsoft Store before Windows Photos or File Explorer can read or write HEIF/HEIC files.

  1. Open the Microsoft Store and search for HEIF Image Extensions.
  2. Install the free extension (published by Microsoft Corporation).
  3. Once installed, open your HEIC file in Photos (double-click it in File Explorer).
  4. Click the three-dot menu in Photos and select Print.
  5. In the Print dialog, choose Microsoft Print to PDF as the printer.
  6. Select your preferred paper size and orientation, then click Print.
  7. Choose a save location in the file save dialog.

The result is a standard PDF containing your image at the selected paper dimensions.

Option B: Convert HEIC to JPG First, Then Create PDF

If the extension installation is not an option (for example, on a managed corporate device), you can convert the HEIC to JPEG or PNG using a third-party image viewer or a free online tool, then convert the JPEG to a PDF.

Quality loss is usually minimal for this type of conversion, though compression settings during the JPG stage can introduce slight differences. To minimize any degradation, save the intermediate JPG at maximum quality (90-100%). After that, the JPG-to-PDF converter at pdf.net handles the final step entirely in the browser.

Quality and File Size of Converted Pictures: What to Expect

HEIC stores photographic data efficiently without visible quality loss at typical shooting resolutions. When you convert to PDF, the outcome depends heavily on the method.

Several practical factors affect the end result, including:

  • Start with full-resolution originals. Avoid cropped or screen-captured versions of HEIC images, which reduce the starting resolution.
  • Avoid draft/low-quality print settings. When printing to PDF on Windows or Mac, leave the quality at the default or highest setting.
  • Check the output before sharing. Open the PDF and zoom in to confirm sharpness before sending to a client or printing.
  • Large file? If the PDF is too large to email, use a PDF compression tool. The guide on compressing PDF without losing quality covers how to reduce file size while retaining acceptable image clarity.

3 Common Issues When Converting HEIC to PDF and Fixes

Most HEIC to PDF problems trace back to a handful of recurring causes, and each one has a straightforward fix. Here are the three issues you're most likely to run into, along with how to resolve them.

  • HEIC won't open on Windows. Install the HEIF Image Extensions from the Microsoft Store (free, published by Microsoft). After installation, restart the Photos app. File Explorer thumbnails should also begin displaying HEIC previews.
  • My PDF is blank, pixelated, or blurry. This usually has one of two causes. First, the print settings were set to a low DPI or draft quality; go back and re-export at the default or high-quality setting. Second, the source HEIC was already a low-resolution image (for example, a screenshot or a heavily cropped photo). There is no recovery path for a low-resolution source; the fix is to use the original full-resolution file.
  • The file is too large to upload, or the conversion fails. First, check the file size of the HEIC. Very large RAW-equivalent HEIC files from newer iPhone models can exceed 20MB each. Try compressing the HEIC using the iPhone's built-in option to shoot in "Most Compatible" format (Settings > Camera > Formats > Most Compatible), or convert a batch of smaller files rather than one very large one. If the PDF output is too large, the PDF compression tool can reduce it significantly.
