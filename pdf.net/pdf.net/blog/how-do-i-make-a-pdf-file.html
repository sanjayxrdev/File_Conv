How Do I Make a PDF File? 7 Ways Explained With Steps

The answer to the question, “How do I make a PDF file?” is multifaceted, as there are several formats and tools you can use to create one.

Alex Chen

Technical Content Specialist

Table of contents

You can make a PDF file using one of the pre-installed programs on your computer, like Microsoft Office, or using cloud-based tools like Google Docs or a dedicated PDF maker tool.

Once you learn how to make a PDF file, your documents will be more readable, professional-looking, and easier to share. Unlike some other file formats, PDF is platform-independent, and its relatively compact size makes PDF files easier to store, download, and transfer.

In this PDF creation guide, we’ll answer the “How do I create a PDF file?” question by explaining seven different methods of doing so. Let’s begin!

Key Takeaways

  • You can easily create PDFs from Microsoft Office programs like Word, Access, Publisher, Excel, and PowerPoint using the built-in Export or Save as PDF/XPS options—no additional software needed.
  • Google Workspace apps such as Docs, Sheets, and Slides allow you to download documents as PDFs directly.
  • Apple tools (Keynote, Numbers) and browsers like Chrome, Safari, Edge, and Firefox also let you export or print to PDF for quick conversions.
  • You can create PDFs from scanned documents or images by using the “Microsoft Print to PDF” or “Export as PDF” feature on Windows and Mac.
  • With pdf.net, you can convert, edit, split, merge, or annotate PDFs online, with no installation required.

How to Create a PDF File from Microsoft Office Products

You can create a PDF file using Microsoft Office programs with no other software or add-in.

Here’s how you can create a PDF from text, data, and designs with Microsoft Word, Access, and Publisher:

Microsoft Word:

  1. Open the document you want to convert from Word to PDF.
  2. Select the File tab from the Ribbon.
  3. Click the Export button in the drop-down menu on the left.
  4. From there, select the Create PDF/XPS Document option and confirm it by clicking the Create PDF/XPS button in the right pane.
  5. Enter the name of the document and save it.

Microsoft Access:

  1. Choose the report or table you want to convert to PDF.
  2. Select the External Data tab and choose the PDF or XPS option.
  3. Type in the name and save the document.

Microsoft Publisher:

  1. Select the document you want to convert from Publisher to PDF.
  2. Open the File menu.
  3. Select the Save As option from the drop-down menu on the left and choose a location for the file you’re creating.
  4. Choose the folder from the right pane.
  5. Enter the document’s name, choose the PDF format from the Save as type list, and then tap on Save.

How to Create a PDF File from Google Docs

Creating a PDF file from Google Docs is fairly simple, thanks to the platform’s versatility. However, keep in mind that this is an online PDF creation option, so you’ll need an internet connection.

Let’s see how to make a PDF file using the Google Docs app:

  1. Log into your Google Drive account.
  2. Open the document you want to convert to PDF or create a new one.
  3. Click the File section on the menu bar.
  4. From the drop-down menu, select Download and choose the PDF format.

How to Make a PDF Document from Spreadsheets and Presentations

Making a PDF document from spreadsheets and presentations helps you share your tables, charts, and slides without compromising their formatting.

#1. PowerPoint/Keynote/Google Slides

Let’s see how to make a PDF file from PowerPoint, Keynote, and Google Slides presentations:

PowerPoint:

  1. Open the presentation you want to convert from PowerPoint to PDF.
  2. Select File from the menu tabs.
  3. Choose the Export option from the side menu.
  4. Tap on the Create PDF/XPS Document and confirm the action by clicking Create PDF/XPS.
  5. Choose the name and location for your PDF file and save it.

Keynote:

  1. Open the presentation you want to convert from Keynote to a PDF document.
  2. Open the File menu from the menu bar.
  3. Hover your cursor over the Export To option in the drop-down menu and then click PDF.
  4. Customize the export options, including image quality, slide range, and password protection.
  5. Tap on Save, choose the location and name for your PDF file, and click Export.

Google Slides:

  1. Open the Google Slides presentation you want to save as a PDF file.
  2. Click on the File tab in the upper left corner.
  3. Hover over the Download option and select PDF Document (*.pdf) from the drop-down menu.

#2. Excel/Google Sheets/Numbers

Here’s how to make a PDF file from Excel, Google Sheets, and Numbers spreadsheets:

Excel:

  1. Open the document you want to convert from Excel to PDF.
  2. Click the File tab on the Ribbon.
  3. Choose the Export option from the side menu.
  4. Click Create PDF/XPS Document and confirm it by selecting the Create PDF/XPS option from the right pane.
  5. Choose the name and location for your PDF document and save it.

Google Sheets:

  1. Open the Google Sheets document you want to save as a PDF file.
  2. Tap on File in the upper left corner.
  3. Hover over the Download option and select PDF (.pdf).
  4. Customize the export options in the side menu and click Export in the upper right corner.

Numbers:

  1. Open the Numbers spreadsheet you want to save as a PDF.
  2. Tap on File in the upper left corner.
  3. Hover over Export To and select the PDF option.
  4. Specify the page range and image quality of your PDF file and click Save.
  5. Choose the location for your file and select Export.

How to Create a PDF File from Scanned Documents

Creating a PDF file from a scanned document allows you to keep its original layout and content while making it easier to share online.

Here’s how to make a PDF file from a scanned document:

  1. Open the document you want to convert to PDF.
  2. Tap on the printer icon in the top bar.
  3. Choose the Microsoft Print to PDF option from the drop-down menu.
  4. Tap on Print, choose the location for the file, enter a name for it, and click Save.

How to Save Webpages as PDFs on Desktop and Mobile

Saving webpages as PDFs lets you preserve the entire page, including formatting, links, and images for offline viewing and sharing.

Let’s see how you can do that from a computer and a mobile device.

#1. Using a Browser (Chrome, Safari, Edge, Firefox)

Let’s see how you can convert a webpage to PDF using a browser, whether you’re a Windows or Mac user.

Windows:

  1. Open the webpage and press Ctrl+P to open the print menu.
  2. From the Destination drop-down menu, choose the Save as PDF option.
  3. Select Save and choose the name and location for your file.

Mac:

  1. Press Command+P to open the print menu.
  2. Select the Save as PDF option from the drop-down menu in the upper right corner and click Save.
  3. Choose the location and name for the file and save it.

#2. From Mobile

Here’s how you can save a webpage as a PDF file from a mobile device:

  1. Select a mobile browser and load the webpage you want to save.
  2. Tap on the three dots in the upper right corner and choose the Share option from the drop-down menu.
  3. Select the printer icon.
  4. Click Save as PDF.

How to Create PDFs from Images

Creating PDFs from images (PNGs, JPGs, screenshots) allows you to share them more easily while maintaining their quality and format. With our PDF tool you can convert PNG to PDF or JPEG to PNG, depending on your needs.

Here’s how you can do it on Windows:

  1. Open the image you want to save as a PDF file.
  2. Select the printer icon in the upper left corner.
  3. Open the Printer drop-down menu and choose the Microsoft Print to PDF option.
  4. Customize the options in the side menu and click Print.
  5. Choose the location and name for your file.

Let’s see how to make a PDF file from an image on a Mac:

  1. Open the image you want to save as a PDF file in Preview.
  2. Click the File tab in the Preview menu and choose the Export as PDF option.
  3. Enter the file's name, choose where to save it, and click Save.
