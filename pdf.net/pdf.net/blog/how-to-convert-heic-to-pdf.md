## What Is HEIC & Why Doesn’t It Convert Smoothly?

HEIC is **Apple's preferred photo format, built on the HEIF (High Efficiency Image File Format) container standard**. This format was designed to store images at roughly half the file size of [JPEG](https://pdf.net/blog/jpeg-vs-pdf) while maintaining comparable or better visual quality. Apple adopted HEIC as the default camera format [beginning with iOS 11](https://support.apple.com/en-tm/116944).

The problem is that HEIC **is not universally supported**. Windows without the correct codec cannot open HEIC files at all. Many web platforms, email clients, and print services only accept JPEG, PNG, or [PDF](https://pdf.net/blog/what-does-pdf-format-mean), and even some older Mac apps struggle with it.

There is one other thing worth knowing before you convert: if your iPhone captured a Live Photo or a photo burst as HEIC, those motion and sequence elements **do not survive the conversion**; the resulting PDF contains a static image only. For most document and sharing workflows, that is exactly what you want; just do not expect an animated or interactive file on the other side.

## How to Convert HEIC to PDF on Windows

Windows gives you **two practical paths** for converting HEIC to PDF, depending on whether you can install additional software on the machine. The recommended route uses Microsoft's free HEIF extension, while the second works even on locked-down or managed devices where installing extensions isn't an option.

### Option A: Install the HEIF Image Extension (Recommended)

Windows does not support HEIC out of the box. As documented by Microsoft (updated June 19, 2026), the [**HEIF Image Extension**](https://support.microsoft.com/en-US/Windows/Apps/Photos/photos-app-video-editor-error-can-t-view-this-file-type) must be installed from the Microsoft Store before Windows Photos or File Explorer can read or write HEIF/HEIC files.

1. Open the **Microsoft Store** and search for **HEIF Image Extensions**.  
![How to Convert HEIC to PDF on Windows](https://cdn.sanity.io/images/i16te7yp/production/8d58de2c45213d6a48c5d8009fff36610c91cf6d-1792x617.png?fit=max&auto=format)
2. Install the free extension (published by Microsoft Corporation).
3. Once installed, open your HEIC file in **Photos** (double-click it in File Explorer).
4. Click the **three-dot menu** in Photos and select **Print**.
5. In the Print dialog, choose **Microsoft Print to PDF** as the printer.
6. Select your preferred paper size and orientation, then click **Print**.
7. Choose a save location in the file save dialog.

The result is a standard PDF containing your image at the selected paper dimensions.

### Option B: Convert HEIC to JPG First, Then Create PDF

If the extension installation is not an option (for example, on a managed corporate device), you can convert the HEIC to JPEG or [PNG](https://pdf.net/blog/png-vs-pdf) using a third-party image viewer or a free online tool, then convert the JPEG to a PDF.

Quality loss is usually minimal for this type of conversion, though compression settings during the JPG stage can introduce slight differences. To minimize any degradation, save the intermediate JPG at maximum quality (90-100%). ## Quality and File Size of Converted Pictures: What to Expect

HEIC stores photographic data efficiently without visible quality loss at typical shooting resolutions. When you convert to PDF, the outcome depends heavily on the method.

Several practical factors affect the end result, including:

- **Start with full-resolution originals.** Avoid cropped or screen-captured versions of HEIC images, which reduce the starting resolution.
- **Avoid draft/low-quality print settings.** When printing to PDF on Windows or Mac, leave the quality at the default or highest setting.
- **Check the output before sharing.** Open the PDF and zoom in to confirm sharpness before sending to a client or printing.
- **Large file?** If the PDF is [too large to email](https://pdf.net/blog/how-to-email-large-pdf-file), use a PDF compression tool. ## 3 Common Issues When Converting HEIC to PDF and Fixes

Most HEIC to PDF problems trace back to a handful of recurring causes, and each one has a straightforward fix. Here are the three issues you're most likely to run into, along with how to resolve them.

- **HEIC won't open on Windows.** Install the HEIF Image Extensions from the Microsoft Store (free, published by Microsoft). After installation, restart the **Photos **app. File Explorer thumbnails should also begin displaying HEIC previews.
- **My PDF is blank, pixelated, or blurry.** This usually has one of two causes. First, the print settings were set to a low DPI or draft quality; go back and re-export at the default or high-quality setting. Second, the source HEIC was already a low-resolution image (for example, a screenshot or a heavily cropped photo). There is no recovery path for a low-resolution source; the fix is to use the original full-resolution file.
- **The file is too large to upload, or the conversion fails.** First, check the file size of the HEIC. Very large [RAW-equivalent](https://www.nist.gov/glossary-term/30461) HEIC files from newer iPhone models can exceed 20MB each. Try compressing the HEIC using the iPhone's built-in option to shoot in "Most Compatible" format (**Settings** > **Camera **> **Formats **> **Most Compatible**), or convert a batch of smaller files rather than one very large one. If the PDF output is too large, the PDF compression tool can reduce it significantly.
