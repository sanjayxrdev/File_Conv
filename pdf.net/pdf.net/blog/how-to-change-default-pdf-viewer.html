How to Change the Default PDF Viewer: 6 Easy Methods

You can change the default PDF viewer by updating the settings on your device (Windows or Mac) or upon opening your PDF.

Sarah Martinez

Senior Product Manager

Table of contents

You can change your default PDF viewer through file settings in Windows or the Get info panel on Mac; this determines which app opens PDFs automatically on your device.

Many systems use a browser or built-in app, which may not always include the tools you need for editing, reviewing, or organizing documents. Knowing how to change the default viewer can help you use your PDFs more efficiently. Follow along as we break down the steps to update on Windows, Mac, and common web browsers.

Key Takeaways

  • A default PDF viewer is the app your operating system automatically uses to open this type of file; it can be a web browser, a built-in system app, or third-party software.
  • Many viewers only support basic reading, so switching to another program can give you access to more features, including editing, filling forms, applying signatures, etc.
  • You can update the default viewer through the Open with option on a PDF or by adjusting the Default apps settings in Windows.
  • On Mac, you can open a PDF file’s Get info panel in Finder, choose a different app under Open with, then select Change all to apply it to all PDFs.
  • Additionally, you can adjust browser settings in Google Chrome, Safari, and Mozilla Firefox to download PDFs instead of opening them automatically.

What Is a Default PDF Viewer?

A default PDF viewer is the app that your device automatically uses to open PDF files. Operating systems assign one to each file type based on your system settings, installed software, or preferences.

For example, when you install a new PDF reader, you may be asked if you want to set it as the default program for PDF files. If you accept, all your PDFs will open with that app unless you change the settings.

Many devices use built-in system tools like Preview on Mac or Microsoft Edge on Windows to open PDFs. Web browsers such as Google Chrome or Mozilla Firefox can also be default viewers since they include PDF readers.

Why Should You Change Your Default PDF Viewer?

You might want to change your default PDF viewer to:

  • Access advanced features. Many default viewers will only let you read the PDF. If you want to edit the text, add annotations, insert images, etc., you will want to switch to an alternative tool.
  • Fill out forms and apply digital signatures. PDFs are commonly used for contracts, NDAs, invoices, and official applications. However, not all default viewers will support filling fields and adding signatures; updating to a different PDF viewer will let you perform these tasks easily.
  • Enjoy more comprehensive document management features. If you regularly work with many PDFs, tools for merging files, splitting pages, organizing documents, or exporting content can make file management far easier.

How to Change the Default PDF Viewer on Windows

You can change the default PDF viewer on Windows in two ways:

#1. Change the Default App in the File Settings

The first method to change the PDF default app in the file’s settings goes like this:

1. Find your PDF file in File Explorer. Right-click on it and select Open with from the dropdown. A list of available programs will appear.

2. Press Choose another app. You will see a window showing compatible apps installed on your device. Select the PDF viewer you want to use.

3. Set your default PDF viewer by selecting the Always button.

You should use this method when you want a quick way to switch the default PDF viewer when accessing the file itself. It works well if you already have the PDF app and simply want to set it as the program that opens PDFs by default.

This method is also helpful if you want to test a different viewer quickly. For example, if you recently installed a new PDF editor or reader, you can set it as the default while opening a file and immediately see how it works.

#2. Change the Default PDF Viewer in the Windows Settings

You can also update the default app for PDF files through your Windows system settings:

1. Open the Settings menu and choose Apps.

2. Press on Default apps.

3. Scroll to the bottom of the page and click Choose default by file type.

4. Find .pdf and select the app that you want to use by clicking + Choose a default.

With this method, if a newly installed PDF editor does not appear in the right-click menu, you may still be able to set it as the default through system settings. It also allows you to review and adjust other file type assignments while you are there.

How to Change the Default PDF Viewer on Mac

To open PDFs with a different program than Preview, follow these steps:

1. Find your PDF in Finder.

2. Right-click on it to access a dropdown and then select Get info. You will see a panel showing details about the file.

3. Scroll down a bit to see Open with.

4. Click the dropdown menu and choose the PDF viewer you want to use from the list of available apps.

5. Click Change all after selecting the app. This changes the default PDF viewer on your Mac.

How to Change the Default PDF Viewer in Your Browser

You can stop PDFs from opening in your browser (Google Chrome, Safari, and Firefox), too; here is how:

Google Chrome

1. Open your browser and click the three dots in the top-right corner to open the dropdown.

2. Choose Settings near the bottom, scroll down, and click Privacy and security.

3. Click on Site settings.

4. Scroll to the Additional content settings, click the dropdown arrow, and select PDF documents.

5. Press the Download PDFs radio button.

Once you enable this, any PDF you click online will download to your computer. Then, you can open it using your preferred PDF viewer.

Safari

PDFs open directly in the browser window by default in Safari. To change this, when you click on the link, right-click it and choose Download linked file from the dropdown.

The PDF will save to your computer rather than opening in Safari. So, you can open it with the PDF viewer that you want.

Firefox

In Mozilla Firefox, you can take these steps to stop PDFs from being opened in the browser automatically:

1. Open the browser and click the three horizontal lines in the top right corner.

2. Select Settings towards the end of the dropdown.

3. Scroll to the General section and find the Files and applications area.

4. Look for Portable Document Format (PDF) in the list of file types.

5. Open the dropdown next to it and select Save file.

What to Do If You Can’t Change the Default PDF Viewer

If you cannot change the default PDF viewer, try:

  • Checking whether the PDF app is properly installed. If the viewer you want to use does not appear in the list of available programs, it may not be installed correctly. Reinstalling or updating it to the latest version can help your operating system recognize it as an option for opening PDF files.
  • Confirming the default app setting was applied. Sometimes, the change does not fully save. You need to go back to your system’s default app settings and confirm that your program is still assigned to .pdf. If not, select it again and apply the change.
  • Restarting your computer. System settings occasionally require a restart before they fully take effect. You can restart your device to refresh file associations and allow the new default viewer to activate.
  • Repairing file associations. In some cases, the file association for PDFs becomes corrupted. You can fix this by resetting the default apps for file types through your system settings or by selecting a different viewer temporarily and then switching back to your preferred program.
  • Look for system restrictions. On work or school computers, your administrators may restrict changes to default apps. If you cannot modify the setting, you may need to request administrator privileges and permissions to change the default PDF viewer.

How to Choose the Right PDF Viewer

To choose the right PDF viewer, think about how you typically use PDF files. If you mostly read them, a lightweight viewer may be all you need. However, if your day-to-day handling involves editing, reviewing, or sharing documents, software with more advanced tools may be better.

Other criteria to consider include:

  • AI-powered tools. Nowadays, many viewers include AI features that can summarize documents, extract key details, or help search through long files. These can help you save time when reviewing PDF reports and research papers.
  • Ease of use. You should look for a viewer that lets you open files quickly, search the content, and move between pages without having to dig through complicated menus. Ease of use makes a big difference when you are handling high volumes of PDFs or are in a rush.
  • Performance with large files. If you often work with image-heavy PDF catalogues, large reports, or technical manuals, you should choose a viewer that loads files quickly and handles complex layouts smoothly.
  • Compatibility with your system. Make sure that the viewer works well with your operating system and integrates with tools you already use, including cloud storage, email attachments, or document management systems.
  • Security options. If you handle sensitive documents that are vulnerable to malware and ransomware, features such as password protection and PDF permission controls can help you protect important information.

How to Change Default PDF Viewer FAQs

#1. How do I remove Adobe as the default PDF reader?

To remove Adobe as the default PDF reader, open your system’s default app settings and change the program associated with PDF. Select another viewer and confirm the change. Once updated, your device won’t make Adobe the default PDF viewer anymore.

#2. Why won’t my computer remember the new PDF viewer?

Your computer might not remember the PDF viewer because the file association did not fully update, the app was not installed correctly, or system permissions prevented the change. Restarting your device, reinstalling the viewer, or resetting the default app often resolves the issue.

#3. Can I set different PDF viewers for different tasks?

You cannot assign multiple default viewers to the same file type at the system level. However, you can open a PDF with a different program when needed by selecting Open with and choosing another app.
