> You can change the default PDF viewer by updating the settings on your device (Windows or Mac) or upon opening your PDF.

You can change your default PDF viewer through file settings in Windows or the_ Get info _panel on Mac; this determines which app opens PDFs automatically on your device.

Many systems use a browser or built-in app, which may not always include the tools you need for editing, reviewing, or organizing documents. Knowing how to change the default viewer can help you use your PDFs more efficiently. Follow along as we break down the steps to update on Windows, Mac, and common web browsers.

## Key Takeaways

- A default PDF viewer is the app your operating system automatically uses to open this type of file; it can be a web browser, a built-in system app, or third-party software.
- Many viewers only support basic reading, so switching to another program can give you access to more features, including editing, filling forms, applying signatures, etc.
- You can update the default viewer through the _Open with_ option on a PDF or by adjusting the _Default apps_ settings in Windows.
- On Mac, you can open a PDF file’s _Get info_ panel in _Finder_, choose a different app under _Open with_, then select _Change all _to apply it to all PDFs.
- Additionally, you can adjust browser settings in Google Chrome, Safari, and Mozilla Firefox to download PDFs instead of opening them automatically.

## What Is a Default PDF Viewer?

A default PDF viewer is **the app that your device automatically uses to open PDF files. **Operating systems assign one to each file type based on your **system settings, installed software, or preferences.**

For example, when you install a new PDF reader, you may be asked if you want to set it as the default program for PDF files. If you accept, all your PDFs will open with that app unless you change the settings.

Many devices use built-in system tools like **_Preview _**on Mac or **_Microsoft Edge_** on Windows to open PDFs. Web browsers such as Google Chrome or Mozilla Firefox can also be default viewers since they include [PDF readers](https://pdf.net/blog/best-pdf-readers).

## Why Should You Change Your Default PDF Viewer?

You might want to change your default PDF viewer to:

- **Access advanced features. **Many default viewers will only let you read the PDF. If you want to [edit the text](https://pdf.net/change-text-in-pdf), add annotations, [insert images](https://pdf.net/blog/how-to-insert-images-into-pdf), etc., you will want to switch to an alternative tool.
- **Fill out forms and apply digital signatures**. PDFs are commonly used for contracts, [NDAs](https://pdf.net/blog/how-to-sign-an-nda), invoices, and official applications. However, not all default viewers will support filling fields and adding signatures; updating to a different PDF viewer will let you perform these tasks easily.
- **Enjoy more comprehensive document management features. **If you regularly work with many PDFs, tools for [merging files](https://pdf.net/blog/how-to-merge-pdfs), splitting pages, organizing documents, or exporting content can make file management far easier.

## How to Change the Default PDF Viewer on Windows

You can change the default PDF viewer on Windows in two ways:

### #1. Change the Default App in the File Settings

The first method to change the PDF default app in the file’s settings goes like this:

1. Find your PDF file in **_File Explorer_**. Right-click on it and select **_Open with_** from the dropdown. A list of available programs will appear.

![Find your PDF file in File Explorer. Right-click on it and select Open with from the dropdown. A list of available programs will appear.](https://cdn.sanity.io/images/i16te7yp/production/363e63ac989710a8cf81dfd0af2efe0755f72357-684x595.png?fit=max&auto=format)

2. Press **_Choose another app_**. You will see a window showing compatible apps installed on your device. Select the PDF viewer you want to use.

3. Set your default PDF viewer by selecting the **_Always _**button.

![Set your default PDF viewer by selecting the Always button](https://cdn.sanity.io/images/i16te7yp/production/bbaf7913fd9e056efb0721c65d0e6ff60e8479da-1206x741.png?fit=max&auto=format)

You should use this method when you want **a quick way to switch the default PDF viewer **when accessing the file itself. It works well if you already have the PDF app and simply want to set it as the program that opens PDFs by default.

This method is also helpful if you want to **test a different viewer quickly**. For example, if you recently installed a new PDF editor or reader, you can set it as the default while opening a file and immediately see how it works.

### #2. Change the Default PDF Viewer in the Windows Settings

You can also update the default app for PDF files through your Windows system settings:

1. Open the _**Settings** _menu and choose **_Apps_**.

![Open the Settings menu and choose Apps](https://cdn.sanity.io/images/i16te7yp/production/36d187e957d5181676bfca9a47c2156728c20786-1062x783.png?fit=max&auto=format)

 3. Scroll to the bottom of the page and click **_Choose default by file type_**.

![Scroll to the bottom of the page and click Choose default by file type](https://cdn.sanity.io/images/i16te7yp/production/74bb214a43d0fad426392770e8d6c4161261edc4-1060x696.png?fit=max&auto=format)

4. Find **.pdf **and select the app that you want to use by clicking **_+ Choose a default_**.

![Find .pdf and select the app that you want to use by clicking + Choose a default](https://cdn.sanity.io/images/i16te7yp/production/d87334104d48d6fe7c21d1532bdc0762f68f62e5-1058x788.png?fit=max&auto=format)

With this method, if a newly installed PDF editor does not appear in the right-click menu, you may still be able to set it as the default through system settings. It also allows you to **review and adjust other file type assignments while you are there.**

## What to Do If You Can’t Change the Default PDF Viewer

If you cannot change the default PDF viewer, try:

- **Checking whether the PDF app is properly installed. **If the viewer you want to use does not appear in the list of available programs, it may not be installed correctly. Reinstalling or updating it to the latest version can help your operating system recognize it as an option for opening PDF files.
- **Confirming the default app setting was applied. **Sometimes, the change does not fully save. You need to go back to your system’s default app settings and confirm that your program is still assigned to .pdf. If not, select it again and apply the change.
- **Restarting your computer. **System settings occasionally require a restart before they fully take effect. You can restart your device to refresh file associations and allow the new default viewer to activate.
- **Repairing [file associations](https://techterms.com/definition/file_association). **In some cases, the file association for PDFs becomes corrupted. You can fix this by resetting the default apps for file types through your system settings or by selecting a different viewer temporarily and then switching back to your preferred program.
- **Look for system restrictions. **On work or school computers, your administrators may restrict changes to default apps. If you cannot modify the setting, you may need to request [administrator privileges](https://www.ibm.com/docs/en/netezza?topic=sm-administrator-privileges) and permissions to change the default PDF viewer.

## How to Choose the Right PDF Viewer

To choose the right PDF viewer, think about how you typically use PDF files. If you mostly read them, a lightweight viewer may be all you need. However, if your day-to-day handling involves editing, reviewing, or sharing documents, software with more advanced tools may be better.

Other criteria to consider include:

- **AI-powered tools. **Nowadays, many viewers include AI features that can [summarize documents](https://pdf.net/blog/summarize-a-pdf-with-ai), extract key details, or help search through long files. These can help you save time when reviewing PDF reports and research papers.
- **Ease of use. **You should look for a viewer that lets you open files quickly, search the content, and move between pages without having to dig through complicated menus. Ease of use makes a big difference when you are handling high volumes of PDFs or are in a rush.
- **Performance with large files. **If you often work with image-heavy [PDF catalogues](https://pdf.net/blog/how-to-make-a-pdf-catalog), large reports, or technical manuals, you should choose a viewer that loads files quickly and handles complex layouts smoothly.
- **Compatibility with your system. **Make sure that the viewer works well with your operating system and integrates with tools you already use, including cloud storage, email attachments, or document management systems.
- **Security options. **If you handle sensitive documents that are [vulnerable to malware](https://www.cisa.gov/sites/default/files/publications/Malware_1.pdf) and ransomware, features such as [password protection](https://pdf.net/blog/how-to-password-protect-a-pdf) and [PDF permission](https://pdf.net/blog/how-to-change-pdf-permissions) controls can help you protect important information.

## How to Change Default PDF Viewer FAQs

### #1. How do I remove Adobe as the default PDF reader?

To remove Adobe as the default PDF reader, **open your system’s default app settings and change the program associated with PDF. **Select another viewer and confirm the change. Once updated, your device won’t make Adobe the default PDF viewer anymore.

### #2. Why won’t my computer remember the new PDF viewer?

Your computer might not remember the PDF viewer because** the file association did not fully update, the app was not installed correctly, or system permissions prevented the change**. Restarting your device, reinstalling the viewer, or resetting the default app often resolves the issue.

### #3. Can I set different PDF viewers for different tasks?

**You cannot **assign multiple default viewers to the same file type at the system level. However, you can open a PDF with a different program when needed by selecting **_Open with_** and choosing another app.
