## How to Insert PDF to Excel: 3 Simple Methods

To insert a PDF into Excel, you can use the following methods: **embedding it as an object, adding it as a hyperlink, or converting the document to Excel**.

Below, we will show you how each of these methods works and what steps to take for each.

### #1. Embed a PDF Into Excel as an Object

If you want to embed a PDF in Excel, you should use the Object feature. By doing this, you can transfer a PDF into Excel.

Let’s break down this process step by step:

1. Open Excel and click **Insert**.  
![How to Insert PDF to Excel](https://cdn.sanity.io/images/i16te7yp/production/596382a70119160337b286167c1d60c5b53b0f2f-803x82.png?fit=max&auto=format)
2. Find **Object** in the **Text** group and select it.  
![Object in the Text group in Excel](https://cdn.sanity.io/images/i16te7yp/production/95609346a44b8f4eb76c364d0715f8b9611c84db-1880x114.png?fit=max&auto=format)
3. In the Object dialogue box, click the **Create from File** tab and then **Browse** to find the document you want to embed.  
![Create from File tab and then Browse to find the document](https://cdn.sanity.io/images/i16te7yp/production/4897bb958623ca3afae284e81ed8b1d44132d071-715x557.png?fit=max&auto=format)
4. Click **OK** to close the dialogue box and adjust your PDF.  
![Close the dialogue box and adjust your PDF](https://cdn.sanity.io/images/i16te7yp/production/eee45707ea082b328ac737dc153023a0560baf19-901x680.png?fit=max&auto=format)

Once you do this, the preview of your PDF will appear in Excel, as you can see above. The first page of your document will appear not as a PDF or [XML](https://www.spiceworks.com/tech/tech-general/articles/what-is-xml/) table but as an image in the spreadsheets. You can reposition the image by hovering your cursor over it, clicking on it, and dragging it to another place after you see the ‘**move**’ icon.

Additionally, you can resize the image by clicking it and using the **upper or bottom left or right edges** to drag the image inward for a smaller size or outward for a bigger size. And if you double-click on the preview, your document will open in your default [PDF reader](https://pdf.net/blog/best-pdf-readers).

This method may not be as complex as using programming languages (e.g., Python libraries), but it has a downside, as it does not allow editing.

Also, inserting a PDF into Excel can make it much larger. This can hinder the sharing or uploading process and require you to [resize your PDF](https://pdf.net/blog/how-to-resize-pdfs) before insertion into Excel to avoid oversized files.

### #2. Insert a PDF Into Excel as a Link

Besides object insertion, you can also link PDFs to an Excel cell, which is another straightforward method to insert PDFs into Excel. You can link either using a clean text anchor or an image anchor if you want a visual thumbnail that readers can click. That said, let’s examine each case in more detail.

#### Link Using a Text Anchor

Here are the steps to link a PDF into Excel using a text anchor:

1. Double-click **Excel** to open it.
2. Select the cell with the text you want to use as an anchor, right-click it, and choose **Link** from the drop-down menu.  
![Insert a PDF Into Excel as a Link](https://cdn.sanity.io/images/i16te7yp/production/85202c9017d3309a945ab9eb7d11d3ccc8eebcca-309x667.png?fit=max&auto=format)
3. Find your document in the **Insert Hyperlink** menu and double-click it or click **OK**.  
![Insert Hyperlink menu in Excel](https://cdn.sanity.io/images/i16te7yp/production/216f0558dc7682b4b3d8cc5926393ad1851c1c1b-911x422.png?fit=max&auto=format)
4. The anchor text will change color and become clickable; click if you want to open your document in a PDF reader.

You can rename your anchor to **fit the file name or align with its purpose** and customize it by changing the font style, size, and color for a cleaner look.

This is also the only method that works in Google Sheets or Excel Online, as you can upload your PDF to a storage cloud and link to it in these online applications.

#### Link Using an Image Anchor

Additionally, you can insert PDFs into Excel as an image and create a hyperlink. This is a similar method to inserting a PDF as an object, involving the following few short steps:

1. Open the spreadsheet document in Excel.
2. Select the cell you want to edit, click **Insert**, and choose **Pictures**.  
![Link Using an Image Anchor](https://cdn.sanity.io/images/i16te7yp/production/8b998a33b9d4fed34998b0e413f480702fd376d4-670x168.png?fit=max&auto=format)
3. Click **Place in Cell**, then choose **This Device** from the **Insert Picture From** dropdown menu.  
![Click Place in Cell, then choose This Device from the Insert Picture](https://cdn.sanity.io/images/i16te7yp/production/ed7d205203300ce131ef5ec7121f6977952d6ed5-362x190.png?fit=max&auto=format)
4. Browse the image in any format (e.g., [TIFF files](https://shorthand.com/the-craft/what-is-a-tiff-file/index.html)) and any image type (a document thumbnail, a report cover sheet, or other [visual aids](https://www.comm.pitt.edu/visual-aids)), then click **Insert**.  
![Browse the image in any format and click Insert](https://cdn.sanity.io/images/i16te7yp/production/e6295ababa3505fe881d18384a78f2c14066bebd-939x589.png?fit=max&auto=format)
5. Right-click the image and select **Link** from the drop-down menu.  
![Right-click the image and select Link](https://cdn.sanity.io/images/i16te7yp/production/b66613dbce1f0760fb059af324da78018f621cb9-339x703.png?fit=max&auto=format)
6. Select your PDF file to become a clickable link with the image as an anchor, in the same way as described in the previous section.

The two ways for PDF to Excel insertion may be similar to embedding an object, but they are more beneficial than embedding. This is because hyperlinks **do not enlarge your files**, leading to difficulties in uploading or similar processes.

## Troubleshooting: PDF Not Displaying Correctly in Excel

PDF not displaying correctly in Excel can be frustrating, but luckily, this issue may not be too difficult to solve. Here are some of the most common causes, along with the best solutions:

- **PDF appears as an icon instead of a preview**. This usually happens when you try the Excel object embedding method, which should result in a clickable preview of your PDF. However, if the result is just an icon, it’s possible that you ticked the **Display as icon** box in the **Object** dialogue box. Make sure that’s unchecked and try embedding the file again.
- **The hyperlink is broken after moving PDF files**. When you move your PDF file to a new location, the link in your Excel will become outdated and no longer work. To fix this, you need to replace the old hyperlink with a new one by following the hyperlink insertion steps described above.
- **The Excel file size is too large after embedding**. The quickest fix for this one is changing the file type to [Excel Binary Workbook](https://www.onlyoffice.com/blog/2025/07/what-is-an-xlsb-file), which reduces the size and is ideal for storing data. Simply go to **File** > **Save As **> **Save as type** and select it from the dropdown menu. Alternatively, you can opt for hyperlinks instead of embedding.
- **PDF won’t open when double-clicked**. There are several possible causes of this, but first, make sure to check whether your PDF is in a restricted viewing mode and disable it if so. Also, verify that your default PDF reader is properly installed and configured.
